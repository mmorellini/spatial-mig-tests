# Replication Materials: A Simulation Approach for the Spatial Testing of Migration Theories

This repository accompanies the article **“A Simulation Approach for the Spatial Testing of Migration Theories”**, published in the *European Journal of Population* (2026).  
DOI: [**10.1007/s10680-026-09770-0**](https://doi.org/10.1007/s10680-026-09770-0)

All analyses were conducted using the **R statistical programming language**.  
R can be downloaded from: https://www.r-project.org/

This repository provides the code necessary to reproduce the empirical analysis and figures presented in the article.

---

## Abstract

Migration research has long been divided between studies of drivers, which focus on the factors shaping migration flows, and studies of patterns, which describe how these flows are organised across space. Theories of migration typically identify and operationalise drivers but are often less explicit about patterns. As a result, migration theories are usually evaluated using goodness-of-fit measures that assess explanatory power but pay limited attention to spatial accuracy.

This article addresses this limitation by introducing a **simulation-based procedure to evaluate the spatial accuracy of migration theories**. Starting from an observed system of origin–destination migration flows, the procedure generates synthetic systems that reflect the spatial outcomes implied by a given theory. These synthetic migration systems are then compared to the observed case to assess spatial accuracy.

The procedure is applied to intra-European migration flows from 2002 to 2021 and illustrated using two long-standing migration theories: the gravity model and migration systems theory. Both theories achieve high explanatory power under conventional goodness-of-fit metrics, and migration systems theory performs better overall. However, the empirical analysis shows that both theories fail to reproduce important spatial features of the European context, including the high level of reciprocity of flows and the observed migration profiles of Eastern and Northern European countries.

These findings highlight how strong statistical fit does not imply accurate spatial representation. Evaluating migration theories through their implied spatial outcomes provides new insights into their limitations and offers a complementary and integrative tool for migration research.

## Data access

The raw data required to run the analysis are **open access** but must be downloaded separately and placed in the `data_raw/` folder before running the scripts. The project uses data from the following sources:

### CEPII Gravity Dataset

Used for bilateral predictors commonly employed in gravity models of migration (e.g., distance, contiguity, shared language).
Data can be accessed on the [**CEPII data portal**](https://www.cepii.fr/CEPII/en/bdd_modele/presentation.asp?id=8).

### Human Migration Database (HMigD)

Used for bilateral migration flow data, which constitute the **main dependent variable** in the analysis. Data can be accessed on the [**HMigD data portal**](https://maciej-jan-danko.shinyapps.io/HMigD_Shiny_App_I/).

Because both datasets are publicly available, no special access permissions should be required. After downloading the relevant files, place them in: `data_raw/`. The preprocessing script `01_load_clean_merge_data.R` reads these files, cleans them, and produces the processed datasets used in the subsequent analysis.

## Overview

This project is organised as an R project and includes scripts for:

- loading, cleaning, and merging data  
- estimating main PPML models  
- running simulations  
- extracting system-level (network) features of simulated and observed migration systems 
- computing Mahalanobis distances between observed and simulated migration systems
- generating plots  
- conducting robustness checks with alternative data ad model specifications  

The repository is structured so that scripts can be run sequentially, with intermediate outputs written to the `data_processed/`, `tables/`, and `figures/` folders.

---

## Repository structure

The repository contains the following folders and files:

- `data_raw/`  
  Stores raw input data. These files are not shared in the repository and need to be obtained separately.

- `data_processed/`  
  Stores cleaned and derived datasets created during preprocessing and analysis.

- `scripts/`  
  Contains the main analysis scripts.

- `scripts/utils/`  
  Contains helper functions used across scripts, including Mahalanobis distance computation, simulation functions, and plotting helpers.

- `figures/`  
  Stores figures generated by the analysis scripts.

- `tables/`  
  Stores tables generated by the analysis scripts.

- `spatial_tests.Rproj`  
  R project file. Opening the project through this file is the recommended way to ensure working directories are set correctly.

---

## Working directory

To run the code, open the repository using `spatial_tests.Rproj` and execute scripts from within the project environment.  
Alternatively, set the repository root as the working directory before running any scripts.

---

## Script order and purpose

The main scripts in `scripts/` are numbered in the order they are typically run.

### Main scripts

- `01_load_clean_merge_data.R`  
  Loads raw data, performs cleaning steps, and merges datasets into analysis-ready files.

- `02_ppml_main_q50.R`  
  Estimates the main PPML models for the `q50` specification (Step 1 of the procedure).

- `03_run_simulations.R`  
  Runs the simulations (Step 2 of the procedure) used in the analysis.

- `04_extract_network_features.R`  
  Computes or extracts spatial features of the migration systems, to be used as inputs in the accuracy assessment (Step 3 of the procedure).

- `05_compute_distances.R`  
  Computes distance between observed and simulated migration systems and spatial features (Step 4 of the procedure).

- `06_make_plots.R`  
  Generates the main figures for the project.

- `07_ppml_all_quantiles.R`  
  Estimates PPML models across all quantiles (alternative `q` values).

- `08_ppml_eurostat_data.R`  
  Runs PPML models using Eurostat-based data inputs.

- `09_ppml_exclude_covid_q50.R`  
  Re-estimates the `q50` PPML models excluding the COVID period.

- `10_make_plots_by_corridor.R`  
  Produces corridor-level plots of observed versus simulated flows.

### Utility scripts

The `scripts/utils/` folder contains helper functions used throughout the project:

- `compute_mahalanobis.R`  
  Functions for computing Mahalanobis-distance-based measures.

- `network_functions.R`  
  Functions for creating or manipulating migration systems and their network or spatial features.

- `plotting_helpers.R`  
  Shared helper functions for formatting and producing plots.

## Reproducibility

To reproduce the full workflow:

1. Place all required raw data files in `data_raw/`.
2. Open `spatial_tests.Rproj`.
3. Run the scripts in numerical order, starting with `01_load_clean_merge_data.R`.

Outputs will be written to:

- `data_processed/`  
- `tables/`  
- `figures/`
